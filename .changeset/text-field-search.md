TextField: the search affordance. `iconStart` puts a decorative glyph inside the field (`type="search"` gets the Search glyph by default), `onClear` adds a clear button that appears once there is a value (named by `clearLabel`), Escape clears too and keeps the event from a surrounding dialog, and `hideLabel` keeps the label for assistive technology only. A plain TextField renders exactly as before. Tokens: `--text-field-icon-*`.
