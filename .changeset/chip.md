Chip (experimental): a pill for a filter that toggles (`selected` / `defaultSelected` / `onSelectedChange`, a native button with `aria-pressed`) or a value that can be removed (`onRemove`), or both. The remove control is a second button beside the label, never inside it, named "Remove" plus the chip's label. `size` (`sm`–`lg`), `tone` (`neutral`, `action`), `disabled`. Tokens: `--chip-*`.
