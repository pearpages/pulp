## Packages

| Package | What it is |
| --- | --- |
| `@pearpages/pulp-tokens` | DTCG JSON source, `tokens.css` and `tokens.json` out |
| `@pearpages/pulp-css` | layer order, reset, base styles; framework-agnostic |
| `@pearpages/pulp-react` | components, one entry per component |

## Use it

Load the brand typefaces yourself (`@fontsource-variable/archivo`, `instrument-sans`,
`geist-mono` for pulp; `nunito`, `inter` for bitepals). Tokens name the families and
fall back to system fonts; they ship no font files.

```css
/* once per app */
@import "@pearpages/pulp-css";
@import "@pearpages/pulp-react/styles.css";
```

```tsx
import { Button } from '@pearpages/pulp-react/button';

<html data-brand="bitepals" data-scheme="dark">
  <Button variant="secondary">Save</Button>
</html>
```
